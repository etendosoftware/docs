# Diferencias con Etendo Classic { #differences-with-etendo-classic }

## Visión general

Esta página recoge las diferencias conocidas entre **Etendo Classic** y la **Nueva UI de Etendo**. Empieza por cómo se gestiona la licencia.

## Límites de la licencia { #license-limits }

Los límites de la licencia de una instalación de Etendo los aplica **Etendo Classic** y **no los aplica la Nueva UI de Etendo**.

| Límite de la licencia | Etendo Classic | Nueva UI de Etendo |
|---|---|---|
| Número máximo de usuarios concurrentes | Se aplica | No se aplica |
| Licencia caducada | Se aplica | No se aplica |
| Módulos comerciales no contratados | Se aplica | No se aplica |
| Cuota de servicios web | Se aplica | No se aplica |

En la Nueva UI de Etendo:

- El inicio de sesión no comprueba la licencia de la instancia.
- Las funcionalidades no se limitan por licencia, por ejemplo los módulos comerciales no contratados.

Etendo Classic sigue aplicando sus límites de licencia como siempre, tanto si se usa solo como junto con la Nueva UI.

!!! info

    Este es el comportamiento actual de la Nueva UI de Etendo y puede cambiar en futuras versiones.

!!! note

    Las condiciones de tu contrato de licencia siguen vigentes sea cual sea la interfaz que uses. Para cualquier duda sobre tu licencia, contacta con tu representante de Etendo.
