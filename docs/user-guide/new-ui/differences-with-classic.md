# Differences with Etendo Classic

## Overview

This page lists the known differences between **Etendo Classic** and the **Etendo New UI**. It starts with how the license is handled.

## License Limits

The license limits of an Etendo installation are applied by **Etendo Classic** and are **not applied by the Etendo New UI**.

| License limit | Etendo Classic | Etendo New UI |
|---|---|---|
| Maximum number of concurrent users | Applied | Not applied |
| Expired license | Applied | Not applied |
| Commercial modules that are not contracted | Applied | Not applied |
| Web services quota | Applied | Not applied |

In the Etendo New UI:

- The login does not check the license of the instance.
- Features are not limited by license, for example commercial modules that are not contracted.

Etendo Classic keeps applying its license limits as usual, whether it is used on its own or together with the New UI.

!!! info

    This is the current behavior of the Etendo New UI and it may change in future versions.

!!! note

    The terms of your license agreement remain in force regardless of the interface you use. For any question about your license, contact your Etendo representative.
