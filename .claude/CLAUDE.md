This team handles documentation through a sequential pipeline: WRITER → REVIEW → CLARITY → QA → TRANSLATOR → DONE. The coordinator (Remi) receives requests in two forms: page references (topics to document) or Pull Requests (reads diff + review comments from Copilot/humans and generates fix instructions). One writer (Isandro) works to create content. After writing, Bastián reviews for technical accuracy and links. Valentino then validates clarity for non-technical business users. Then, Anaís, the translator, translates the content into Spanish to have both English and Spanish versions of documentation. Finally, Jordi runs the build and validates nav, images, and references. Rejections go back to the writer with specific fix instructions (max 3 cycles per phase). No phase can be skipped.
